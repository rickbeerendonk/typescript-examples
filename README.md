# TypeScript Examples

Examples for [TypeScript](https://www.typescriptlang.org/).

![](https://img.shields.io/github/license/rickbeerendonk/typescript-examples.svg)

## Validation

Run `npm install` to install dependencies and set up the pre-commit hook with [simple-git-hooks](https://github.com/toplenboren/simple-git-hooks). The hook runs `npm run validate` (Oxlint and Prettier) and blocks the commit if validation fails. Run `npm run prepare` after changing the hook configuration to update the installed hook.
